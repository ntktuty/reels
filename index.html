வீடியோ பதிவேற்றியவர்களின் பட்டியல் — பெயர், செல்போன் நம்பர், பதிவேற்றிய வீடியோக்களின் எண்ணிக்கை. தேவையற்ற முறையில் பயன்படுத்துபவர்களை தடை செய்யலாம்.

நேரடியாக ஒரு நம்பரை தடை செய்ய

உள் நுழைந்தவர்கள் பட்டியல் (பெயர் · செல்போன் · நேரம்)

வீடியோ பதிவேற்றாமலேயே app-ஐ திறந்தவர்கள் உட்பட, உள்நுழைந்த ஒவ்வொருவரும் இங்கே தெரியும்.

☁️ அனைத்து டிவைஸிலும் ஒரே தரவு (Cloud Sync)

முக்கியம்: கீழே "சேமிக்கவும்" பொத்தானை அழுத்தி சேர்க்கும் URL இந்த சாதனத்தில் மட்டும் வேலை செய்யும். அனைத்து கம்யூட்டர்/போன்களிலும் தானாக Sync ஆக வேண்டுமெனில், கீழே உள்ள Apps Script Web App URL-ஐ, இந்த HTML கோப்பிற்குள் BUILT_IN_WEBHOOK என்ற இடத்தில் ஒரு முறை ஒட்டி, அந்த ஒரே கோப்பை (அப்டேட் செய்யப்பட்டதை) அனைவரும் பயன்படுத்தும் இணையதளத்தில் பதிவேற்றவும். பின் யாரும் தனியாக செட்டிங் செய்யத் தேவையில்லை.

📋 Apps Script கோட் + அமைக்கும் வழிமுறை

  3. Deploy → New deployment → Web app → Execute as: Me, Who has access: Anyone
